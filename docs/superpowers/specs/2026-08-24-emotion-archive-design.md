# 감정 아카이브 웹사이트 설계

## 목적

30–50대 성인이 일, 관계, 가족 안에서 반복되는 마음의 패턴을 이해하도록 돕는 독립 심리 콘텐츠 브랜드를 만든다. 콘텐츠가 사이트의 중심이며, 읽기만으로 정리되지 않는 사용자가 상담 안내로 자연스럽게 이동하게 한다.

## 전제

- 브랜드는 기존 참고 사이트와 분리된 독립 브랜드다.
- 디자인 작업명은 `감정 아카이브`, 초기 표시 이름은 `마음의 장면들`로 사용한다.
- 최종 브랜드명, 로고, 원고, 연락처, 예약 주소는 이후 제공된다.
- 교체 예정 정보는 코드에 흩어놓지 않고 중앙 설정과 콘텐츠 데이터로 분리한다.
- 참고 사이트의 콘텐츠 범위와 전환 방식을 분석하되 문장과 시각 표현은 복제하지 않는다.
- `DESIGN-cal.md`는 타이포 계층, 그리드, 여백, 컴포넌트 원칙의 참고 자료로만 사용한다.

## 사용자와 핵심 흐름

핵심 사용자는 일, 관계, 가족 문제가 서로 얽혀 있다고 느끼는 30–50대 성인이다.

1. 메인 화면에서 자신의 현재 고민과 가까운 영역을 발견한다.
2. 대표 글 또는 최신 글을 읽는다.
3. 관련 글로 탐색을 이어간다.
4. 읽기만으로 해결되지 않을 때 글의 끝에서 상담 안내를 확인한다.
5. 외부 카카오톡 또는 예약 페이지로 이동한다.

상담 전환은 첫 화면부터 반복적으로 압박하지 않는다. 콘텐츠를 충분히 읽은 뒤 맥락에 맞게 한 번 제안한다.

## 시각 정체성

### 방향

심리상담 홍보 사이트보다 독립 출판물과 연구 기록실에 가까운 편집형 인상을 만든다. 전문성은 분명하게, 감정 표현은 절제한다.

### 색상

- 캔버스: 따뜻한 아이보리
- 주색: 짙은 포레스트 그린
- 포인트: 절제된 테라코타
- 본문: 완전한 검정보다 부드러운 짙은 회색
- 구분선: 저대비 웜 그레이

구체적인 색상값은 구현 계획에서 접근성 대비 기준을 확인해 확정한다.

### 타이포그래피

- 큰 제목: 단단한 인상의 한국어 고딕체, 중간 굵기, 촘촘한 자간
- 본문과 UI: 가독성 높은 중립적 한국어 고딕체
- 영문 라벨: 작은 대문자와 넓은 자간으로 기록물의 색인 느낌을 만든다.
- 제목은 크기로 강조하며 과한 굵기를 사용하지 않는다.

### 레이아웃과 형태

- 데스크톱 최대 콘텐츠 폭은 약 1200px다.
- 섹션 간 여백을 크게 두고 얇은 구분선으로 편집 리듬을 만든다.
- 카드의 모서리는 낮게 둥글리거나 직각에 가깝게 처리한다.
- 그림자는 거의 사용하지 않는다.
- 콘텐츠 목록은 카드 타일보다 제목, 분류, 읽기 시간을 중심으로 구성한다.
- 사진은 감정적인 인물 클로즈업보다 공간, 사물, 일상의 장면을 사용한다.

## 정보 구조

### 전역 내비게이션

- 브랜드 로고
- 일
- 관계
- 가족
- 마음 기록
- 상담 안내

모바일에서는 접근 가능한 메뉴 버튼과 전체 화면 또는 드로어형 메뉴로 축약한다.

### 메인페이지

1. **상단 내비게이션**: 브랜드와 주요 주제 접근
2. **히어로**: 큰 브랜드 문장, 한 줄 설명, `글 둘러보기`, 이번 주 핵심 주제 3개
3. **삶의 영역**: `일과 번아웃`, `관계와 회복`, `가족과 성장`
4. **에디터 추천**: 대표 글 한 편을 크게 소개
5. **최신 기록**: 분류, 제목, 요약, 읽기 시간 중심 목록
6. **마음의 문장**: 짧은 인사이트로 화면 호흡 전환
7. **상담 연결**: 콘텐츠 탐색 이후의 선택지로 상담 안내 제공
8. **푸터**: 운영 주체, 연락처, 예약, 법적·의료적 고지

### 주제 페이지

- 주제명과 짧은 소개
- 대표 글
- 최신 글 목록
- 다른 주제로 이동하는 색인
- 페이지 하단 상담 안내

### 글 상세 페이지

- 분류, 제목, 요약, 읽기 시간
- 본문
- 관련 글 최대 3개
- 상담 안내
- 운영 및 의료 고지

### 상담 안내 페이지

- 상담이 도움이 될 수 있는 상황
- 진행 방식
- 운영 주체와 연락 정보
- 외부 예약 및 카카오톡 연결
- 응급 상황과 의료 진단을 대체하지 않는다는 고지

## 콘텐츠 모델

원고는 한 데이터 계층에서 관리한다. 각 글은 다음 필드를 가진다.

- `slug`
- `category`
- `title`
- `summary`
- `readingTime`
- `publishedAt`
- `featured`
- `body`
- `relatedSlugs`
- `seoTitle`
- `seoDescription`
- `shareImage`

사이트 설정은 브랜드명, 설명, 연락처, 카카오톡 주소, 예약 주소, 지도 주소, 운영 주체, 고지 문구를 한곳에서 관리한다.

초기 구현에는 레이아웃을 검증할 수 있는 짧은 임시 원고를 포함한다. 임시 원고는 최종 원고와 혼동되지 않도록 데이터 파일에 명시적으로 표시한다.

## 상호작용

- 검색과 복잡한 필터는 초기 범위에서 제외한다.
- 링크와 버튼은 명확한 포커스 상태를 제공한다.
- 애니메이션은 짧은 등장과 버튼 반응으로 제한한다.
- `prefers-reduced-motion`을 존중한다.
- 상담 링크는 사용자가 클릭할 때만 외부 페이지로 이동한다.

## 반응형과 접근성

- 320px 이상의 모바일 화면부터 넓은 데스크톱까지 지원한다.
- 데스크톱의 2–3열 구성은 모바일에서 단일 열로 전환한다.
- 본문 줄 길이를 읽기 편한 범위로 제한한다.
- 색상 대비, 키보드 탐색, 의미 있는 제목 구조, 대체 텍스트를 제공한다.
- 터치 대상은 최소 44px를 목표로 한다.

## SEO와 메타데이터

- 페이지별 제목과 설명
- canonical URL
- Open Graph 및 공유 이미지 자리
- 글 상세의 Article 구조화 데이터
- 주제별 내부 링크
- 사이트맵과 robots 설정

최종 도메인과 브랜드명이 확정되기 전에는 중앙 설정값으로 관리한다.

## 오류와 빈 상태

- 존재하지 않는 글 주소는 브랜드 스타일의 404 화면으로 연결한다.
- 관련 글이 없으면 해당 영역을 숨긴다.
- 외부 상담 주소가 설정되지 않으면 버튼을 비활성화하지 않고 상담 안내 페이지 내부 연락 문구로 대체한다.
- 이미지 누락 시 장식용 색면 또는 텍스트 중심 레이아웃으로 자연스럽게 대체한다.
- 잘못된 필수 콘텐츠 데이터는 개발 환경에서 명확한 검증 오류를 표시한다.

## 구현 경계

초기 버전은 정적 콘텐츠 중심 웹사이트다. 회원가입, 댓글, 관리자 화면, 진단 도구, 결제, 자체 예약 시스템, 다국어 기능은 포함하지 않는다. 상담 예약은 기존 외부 서비스로 연결한다.

## 검증 기준

- 메인, 주제, 글 상세, 상담 안내, 404 화면이 모두 렌더링된다.
- 사이트 설정과 원고 데이터 교체가 레이아웃 코드 수정 없이 가능하다.
- 모바일 메뉴와 모든 주요 링크가 키보드로 동작한다.
- 320px, 768px, 1200px 화면에서 가로 넘침과 텍스트 겹침이 없다.
- 빌드, 타입 검사, 린트가 통과한다.
- 주요 페이지의 제목, 설명, canonical, 구조화 데이터가 확인된다.
- 상담 연결은 콘텐츠보다 앞서 과도하게 반복 노출되지 않는다.

## 승인된 결정

- 콘텐츠와 상담 전환을 결합한다.
- 독립 브랜드로 만든다.
- 핵심 사용자는 관계, 일, 가족을 함께 다루고 싶은 30–50대 성인이다.
- 시각 방향은 `감정 아카이브`다.
- 메인페이지와 콘텐츠 기능 범위는 본 문서의 구조를 따른다.
- 최종 원고는 이후 제공하며 초기 구현에는 교체 가능한 임시 원고를 사용한다.
